# 题目01 电商订单交易系统 · 数据字典（Database Dictionary）

| 项目 | 内容 |
| --- | --- |
| 数据库 | MySQL 8.x（库名建议 `shop_t01`） |
| 金额规则 | 全部 `BIGINT` 存「分」，禁止浮点 |
| 时间规则 | `DATETIME`，服务端时间；待付款超时用可配置教学时钟 |
| 版本 | V1.0（2026-11-15） |

## 0. 公共约定

- 主键 `id BIGINT UNSIGNED AUTO_INCREMENT`（订单号除外，用字符串）。
- 所有状态字段用**字符串枚举**，取值见各表说明。
- 金额字段命名含 `amount`/`price` 的均为「分」。
- 订单号 `id`：`VARCHAR(32)`，格式 `T01` + 日期 + 序号（如 `T0120261115001`）。

## 1. user 用户表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| username | VARCHAR(64) | NOT NULL, UNIQUE | 登录账号 |
| password_hash | VARCHAR(128) | NOT NULL | 密码哈希（演示账号可预置） |
| role | VARCHAR(20) | NOT NULL | `buyer`/`operator`/`warehouse`/`service` |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |

预置账号：buyer1/buyer2/buyer3、operator、warehouse、service（密码同用户名，仅演示）。

## 2. product 商品表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| name | VARCHAR(128) | NOT NULL | 商品名 |
| price | BIGINT | NOT NULL | 单价（分） |
| stock | INT | NOT NULL | 当前可售数量（下单扣减、释放加回） |
| status | VARCHAR(10) | NOT NULL DEFAULT 'off' | `on` 在售 / `off` 下架 |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NULL | 更新时间 |

预置：商品A 10000 分 / stock 5；商品B 8000 分 / stock 10。

## 3. order 订单表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | VARCHAR(32) | PK | 订单号 |
| buyer_id | BIGINT | NOT NULL, INDEX | 买家 |
| product_id | BIGINT | NOT NULL | 商品 |
| product_name | VARCHAR(128) | NOT NULL | 商品名快照 |
| price_snapshot | BIGINT | NOT NULL | 下单时单价快照（分） |
| quantity | INT | NOT NULL | 数量 1~2 |
| total_amount | BIGINT | NOT NULL | 总金额（分）= 单价×数量 |
| status | VARCHAR(20) | NOT NULL, INDEX | 见下方状态枚举 |
| created_at | DATETIME | NOT NULL | 下单时间 |
| expired_at | DATETIME | NOT NULL | 待付款超时时间 |
| updated_at | DATETIME | NULL | 更新时间 |

**status 枚举**：

| 值 | 含义 |
| --- | --- |
| PENDING_PAYMENT | 待付款 |
| PAID | 待发货（已付款确认） |
| REFUND_PENDING | 退款申请中（客服待审核） |
| REFUND_PROCESSING | 退款处理中（渠道执行中） |
| REFUND_FAILED | 退款失败（待重试） |
| REFUNDED | 已退款 |
| SHIPPED | 已发货 |
| CLOSED | 已关闭（取消/超时） |
| PAYMENT_ABNORMAL | 支付异常（迟到支付待退款） |

## 4. payment 支付流水表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| order_id | VARCHAR(32) | NOT NULL, INDEX | 订单号 |
| channel_txn_no | VARCHAR(64) | NOT NULL, UNIQUE | 渠道交易号（全局唯一，幂等依据） |
| amount | BIGINT | NOT NULL | 支付金额（分） |
| status | VARCHAR(20) | NOT NULL | `pending`/`success`/`failed` |
| notify_at | DATETIME | NULL | 通知到达时间 |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 5. refund 退款单表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| order_id | VARCHAR(32) | NOT NULL, INDEX | 订单号 |
| payment_id | BIGINT | NULL | 关联支付流水 |
| amount | BIGINT | NOT NULL | 退款金额（分） |
| type | VARCHAR(20) | NOT NULL | `sale` 售前退款 / `late_payment` 迟到支付退款 |
| status | VARCHAR(20) | NOT NULL | 见下方枚举 |
| reason | VARCHAR(255) | NULL | 原因 |
| retry_count | INT | NOT NULL DEFAULT 0 | 重试次数 |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NULL | 更新时间 |

**status 枚举**：`pending` 待审核 / `processing` 渠道退款中 / `success` 成功 / `failed` 失败（可重试）。

> 关键区别：`type=sale` 退款成功需恢复库存；`type=late_payment` 退款成功**不**恢复库存（已释放过）。

## 6. shipment 发货单表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| order_id | VARCHAR(32) | NOT NULL, UNIQUE | 订单号（一单一发） |
| carrier | VARCHAR(64) | NOT NULL | 承运方 |
| tracking_no | VARCHAR(64) | NOT NULL | 运单号 |
| operator_id | BIGINT | NOT NULL | 操作人（仓库） |
| shipped_at | DATETIME | NOT NULL | 发货时间 |

## 7. payment_abnormal 异常支付表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| order_id | VARCHAR(32) | NOT NULL, INDEX | 订单号 |
| channel_txn_no | VARCHAR(64) | NOT NULL | 渠道交易号 |
| amount | BIGINT | NOT NULL | 金额（分） |
| status | VARCHAR(20) | NOT NULL | `pending` 待处理 / `refunded` 已退款 |
| reason | VARCHAR(255) | NULL | 原因（如 late_payment） |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 8. role_permission 角色权限表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| role | VARCHAR(20) | NOT NULL | 角色 |
| resource | VARCHAR(64) | NOT NULL | 资源 |
| action | VARCHAR(32) | NOT NULL | 动作 |

> 权限矩阵见需求文档 §2.2；RBAC 可在代码中静态映射，本表用于固化与审计。

## 9. order_event 订单事件表（追溯）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| order_id | VARCHAR(32) | NOT NULL, INDEX | 订单号 |
| event | VARCHAR(32) | NOT NULL | 事件类型 |
| detail | VARCHAR(255) | NULL | 详情 |
| operator_id | BIGINT | NULL | 操作人 |
| created_at | DATETIME | NOT NULL DEFAULT CURRENT_TIMESTAMP | 时间 |

**event 枚举**：created / paid / cancelled / timeout_closed / refund_apply / refund_approved / refund_rejected / refund_success / refund_failed / refund_retry / shipped / payment_abnormal / abnormal_refunded

> 作用：保证 BR-08「异常记录不能通过直接修改订单状态消失」，全链路可追溯。
