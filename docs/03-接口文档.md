# 题目01 电商订单交易系统 · 接口文档（API Specification）

| 项目 | 内容 |
| --- | --- |
| BaseURL | `http://<host>:8080` |
| 鉴权 | JWT（`Authorization: Bearer <token>`）；登录与 `/pay/notify` 除外 |
| 版本 | V1.0（2026-11-15） |

## 0. 通用约定

### 0.1 统一响应结构
```json
{ "code": 0, "message": "ok", "data": {} }
```
- `code=0` 成功；非 0 为业务错误码。
- 金额字段一律为「分」的整数。

### 0.2 通用错误码
| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | 40000 | 参数错误/校验失败 |
| 401 | 40100 | 未认证（token 缺失/无效/过期） |
| 403 | 40300 | 无权限（角色不符/越权访问他人资源） |
| 404 | 40400 | 资源不存在 |
| 409 | 40900 | 状态冲突（非法状态迁移/重复操作） |
| 422 | 42200 | 业务规则拒绝（库存不足/金额不符/验签失败等） |
| 500 | 50000 | 服务器内部错误 |

## 1. 登录
- `POST /api/login`
- 鉴权：无
- 请求体：`{ "username": "buyer1", "password": "buyer1" }`
- 响应：`{ "code":0, "data": { "token":"...", "role":"buyer", "user_id":1 } }`

---

## 2. 用户端（买家）

### 2.1 商品列表
- `GET /api/products`　鉴权：需登录
- 响应：`data: [ { "id":1, "name":"...", "price":10000, "stock":5, "status":"on" } ]`（仅返回在售）

### 2.2 商品详情
- `GET /api/products/{id}`　鉴权：需登录
- 响应：`data: { "id":1, "name":"...", "price":10000, "stock":5, "status":"on" }`

### 2.3 下单
- `POST /api/orders`　鉴权：买家
- 请求体：`{ "product_id":1, "quantity":1 }`（quantity 1~2）
- 成功：`data: { "order_id":"T01...", "total_amount":10000, "status":"PENDING_PAYMENT", "expired_at":"..." }`
- 失败：库存不足/商品下架 → 42200；数量非法 → 40000

### 2.4 我的订单列表
- `GET /api/orders`　鉴权：买家（仅本人）
- 响应：`data: [ { "id":"T01...", "product_name":"...", "quantity":1, "total_amount":10000, "status":"PAID", "created_at":"..." } ]`

### 2.5 订单详情
- `GET /api/orders/{id}`　鉴权：买家（仅本人，否则 403）
- 响应：订单 + 支付流水 + 退款单 + 发货单（含运单）+ 事件

### 2.6 取消订单
- `POST /api/orders/{id}/cancel`　鉴权：买家（仅本人待付款）
- 成功：状态 → `CLOSED`，释放库存；非待付款 → 40900

### 2.7 发起支付
- `POST /api/orders/{id}/pay`　鉴权：买家（仅本人待付款）
- 成功：`data: { "pay_url":"https://openapi-sandbox.dl.alipaydev.com/gateway.do?...", "out_trade_no":"..." }`
- 已付款/已关闭 → 40900

### 2.8 申请售前退款
- `POST /api/orders/{id}/refund`　鉴权：买家（仅本人已付款未发货）
- 请求体：`{ "reason":"..." }`
- 成功：状态 → `REFUND_PENDING`；不可退款状态 → 40900

---

## 3. 支付回调

### 3.1 支付宝沙箱异步通知（真实）
- `POST /pay/notify`　鉴权：无（验签）
- 处理：验签 → 匹配订单 → 匹配金额 → 幂等确认 → 状态 PAID；金额不符/未知订单/验签失败 → 拒绝并登记通知
- 迟到（订单已 CLOSED）→ 登记 `payment_abnormal`，不恢复订单/库存
- 响应：`"success"` / `"fail"`

### 3.2 可控回调网关（异常注入，教学演示）
- `POST /api/admin/pay/mock-notify`　鉴权：运营/客服
- 请求体：`{ "out_trade_no":"...", "amount":10000, "result":"success|fail", "mode":"repeat|late|bad_sign|wrong_amount|unknown" }`
- 用于注入：成功/失败/超时/重复/迟到/验签失败/金额不符/未知订单

---

## 4. 管理端 · 运营

### 4.1 商品管理列表
- `GET /api/admin/products`　鉴权：运营
- 响应：全量商品（含下架）

### 4.2 上架/下架
- `POST /api/admin/products/{id}/shelf`　鉴权：运营
- 请求体：`{ "status":"on|off" }`

### 4.3 改售价/库存
- `PUT /api/admin/products/{id}`　鉴权：运营
- 请求体：`{ "price":12000, "stock":10 }`

### 4.4 库存看板
- `GET /api/admin/products/stock`　鉴权：运营
- 响应：`data: [ { "id":1, "name":"...", "stock":5 } ]`

### 4.5 交易汇总
- `GET /api/admin/summary`　鉴权：运营
- 响应：`data: { "paid_total":50000, "refunded_total":10000, "shipped_count":1, "abnormal_count":1 }`

### 4.6 订单记录
- `GET /api/admin/orders/{id}/records`　鉴权：运营
- 响应：收款/退款/发货/异常/事件记录

---

## 5. 管理端 · 仓库（商家）

### 5.1 可发货订单
- `GET /api/admin/ship/pending`　鉴权：仓库
- 响应：`data: [ { "id":"T01...", "product_name":"...", "buyer":"...", "total_amount":10000 } ]`（仅 PAID，退款申请中不出现）

### 5.2 发货登记
- `POST /api/admin/ship/{id}`　鉴权：仓库
- 请求体：`{ "carrier":"顺丰速运", "tracking_no":"SF1234567890" }`
- 成功：状态 → `SHIPPED`；非待发货/已发货 → 40900

### 5.3 已发货列表
- `GET /api/admin/ship/shipped`　鉴权：仓库
- 响应：已发货订单 + 承运方 + 运单号

---

## 6. 管理端 · 客服

### 6.1 退款待审核
- `GET /api/admin/refunds/pending`　鉴权：客服
- 响应：`data: [ { "id":1, "order_id":"T01...", "amount":10000, "type":"sale", "reason":"..." } ]`

### 6.2 同意退款
- `POST /api/admin/refunds/{id}/approve`　鉴权：客服
- 请求体：`{ "remark":"同意售前退款" }`
- 成功：状态 → `processing`（渠道退款中）；售前退款成功后恢复库存

### 6.3 拒绝退款
- `POST /api/admin/refunds/{id}/reject`　鉴权：客服
- 请求体：`{ "reason":"订单已进入发货流程" }`（必填）
- 成功：订单恢复 `PAID`（可发货）

### 6.4 退款重试
- `POST /api/admin/refunds/{id}/retry`　鉴权：客服
- 成功：`failed` → 重新发起渠道退款；售前退款成功后恢复库存

### 6.5 异常支付列表
- `GET /api/admin/pay-abnormal`　鉴权：客服
- 响应：迟到支付待处理列表

### 6.6 异常支付退款
- `POST /api/admin/pay-abnormal/{id}/refund`　鉴权：客服
- 成功：退款并标记 `refunded`；**不恢复库存**

---

## 7. 鉴权与越权说明

- 买家接口必须校验 `order.buyer_id == 当前用户`，否则 403。
- 管理端接口按角色校验：运营只能访问 §4、仓库只能访问 §5、客服只能访问 §6。
- 身份一律取自 JWT，不信任请求参数中的用户编号。
